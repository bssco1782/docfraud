--------------------------------
LIMITATIONS
--------------------------------
- Held-out accuracy 60.00% is below the 78% sprint target. The model flags 5/10 genuine documents (FPR 50.00%) - for an NBFC this means many good applicants sent to manual review.
- It misses 1/5 tampered documents (FNR 20.00%).
- n=15 (10 genuine / 5 tampered): one image moves accuracy by 6.7 points and recall by 20 points. Wide uncertainty; not a stable estimate.
- The deployed artifact was refit on all 75 images including the test set, so there is no clean held-out number for the exact bytes in production. The replica has identical config and data minus the 15 test images.
- The 22 features are whole-image statistics; tampering in this dataset is local. Day-5 CV on train only gave 58.3% for these features, consistent with this result.
- The better-scoring local-forensics-v1 representation (CV 73.3%) has no finalized model and was not evaluated here - doing so now would be test-set model selection.
- Data is synthetic (3 templates, 4 simple tamper methods). No real NBFC documents; real-world performance is unknown.
- Risk score is an uncalibrated RF vote fraction; do not present it as a probability.
- ModelAPI.predict returns flagged_regions=[] always; the API gives no localisation evidence.
- Images above 2000 px are downscaled before feature extraction; very small images are processed but carry little information, so their scores are not meaningful.
- Large inputs are slow: 13.2s for the 2550x3150 case (feature extraction runs twice there: once directly, once via ModelAPI).
