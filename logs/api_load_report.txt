4. BOTTLENECKS IDENTIFIED
================================================================================
1. CPU-Bound Image Feature Extraction:
   - Error-Level Analysis (ELA), Canny edge detection, and statistical moments require significant CPU cycles per megapixel.
   - Initial implementation executed analyze_document directly on the single-threaded asyncio event loop, blocking all concurrent I/O.
2. Repetitive Image Decoding:
   - Pre-optimization code loaded and converted images from disk multiple times during feature extraction.
3. Thread Contention during Startup:
   - Unsynchronized lazy model loading risked race conditions when concurrent requests arrived before model warm-up.
4. OS Temporary File I/O:
   - Converting multipart upload byte streams to disk-based temporary files adds filesystem overhead on high concurrency.
