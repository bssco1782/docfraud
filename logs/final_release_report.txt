7. KNOWN LIMITATIONS
------------------------------------------------------------------------------
  Model
  - 60% held-out accuracy (precision 44%, recall 80%, 50% false-positive rate)
    on 15 synthetic test documents; target 78% not met.
  - Trained and evaluated on synthetic documents only; real-world accuracy unknown.
  - The deployed model file was refit on all 75 documents, including the test set.
  - 2/5 correct on the demo set (a demonstration record, not an accuracy estimate).
  - tamper_risk_score is an uncalibrated vote fraction, not a fraud probability.
  - flagged_regions is always empty: edits are not localised.
  API
  - `threshold` query parameter is validated but ignored.
  - Only the first page of a PDF is analysed.
  - ~4 documents/s per process; > ~10 concurrent users exceed 2 s latency.
  - Validated on Linux only in this session (Day 5 load tests ran on Windows);
    macOS not tested.
